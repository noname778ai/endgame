2. QUICK START
--------------------------------------------------------------------------------
  # 0) pehle offline self-test - sab kuch sahi chal raha hai ya nahi
  python3 wasp.py selftest

  # 1) scope banao (interactive, authorized confirm + profile choose)
  python3 wasp.py wizard
     # ya manually: cp scope.authorized.example.json scope.json && nano scope.json

  # 2) pre-flight (scope hygiene + tools + DNS + output dir)
  python3 wasp.py verify

  # 3) phase-by-phase (resumable; phase number bhi chalega)
  python3 wasp.py run --module understand        # P2
  python3 wasp.py run --module passive           # P3
  python3 wasp.py run --module active            # P4
  python3 wasp.py run --module content           # P5  (ya: --module 5)
  python3 wasp.py run --module tech              # P6
  python3 wasp.py run --module js                # P7
  python3 wasp.py run --module surface           # P8
  python3 wasp.py run --module auth              # P9
  python3 wasp.py run --module sessions          # P10

  # ya poora pipeline ek command me (complete modules SKIP hote hain)
  python3 wasp.py runall

  # WAF tight ho? stealth preset: 1.2 rps + jitter + UA rotation + retries
  python3 wasp.py run --module 5 --profile stealth
  # ya single-run overrides:
  python3 wasp.py run --module content --rate 2 --max-requests 5000 --proxy http://127.0.0.1:8080

  # 4) progress / results
  python3 wasp.py status                        # table + findings count (--json bhi)
  python3 wasp.py findings --min-sev medium     # cross-module rollup
  python3 wasp.py evidence --tail 20            # live request tail
  python3 wasp.py chain                         # kya phase kya feed karta hai
  python3 wasp.py report                        # engagement REPORT.md

  # 5) environment shak me ho to
  python3 wasp.py doctor                        # files/checkpoints/cache/integrity
  python3 wasp.py doctor --fix                  # corrupt checkpoints auto-clean

5. SAFETY (ye engine khud enforce karta hai)
--------------------------------------------------------------------------------
  * Scope firewall    - sirf allowed host par request; vhost probing bhi Host name
                        authorize karta hai, raw IP ko nahi. Out-of-scope = blocked.
                        (ULTRA BF3: targets me explicitly likhe hosts bhi allowed)
  * Budget kill-switch- config.max_requests ke baad koi request nahi jayegi.
  * Adaptive throttle - WAF/429 dikhe to apne aap slow ho jata hai (jitter ke sath).
  * Read-only default - PUT/DELETE/TRACE kabhi nahi bhejte; upload sirf opt-in.
  * No secret misuse  - secrets hamesha REDACTED store hote hain (ULTRA scan_secrets
                        bhi redacted hi return karta hai).
  * Cross-host redirect par Authorization/Cookie header strip ho jate hain
    (ULTRA: redirect follow karna ab manual + scope-checked hai - BF1).
  * Negative cache    - dead host:port ko dobara nahi peeta (noise kam).
  * allow_destructive - default false; --allow-destructive sirf RoE permit ho tab.

8. TROUBLESHOOTING
--------------------------------------------------------------------------------
  "SCOPE BLOCKED"                  -> scope.json me authorized=true + targets daalo
                                      (ya wasp.py wizard chalao)
  "No in-scope seeds"              -> v2 me ye tab aata tha jab sirf targets thin;
                                      ULTRA BF3 fix - agar phir bhi aaye to
                                      domains/ips bhi bhar do
  "no response" sab targets par     -> host down / TLS / proxy galat / out-of-scope
  Phase 5 bahut slow                -> WASP_WORDS=1500 python3 wasp.py run --module content
                                      (ya config me content_total_cap kam karo)
  Phase 5 false positives           -> server 200-on-missing deta hai; engine similarity
                                       se filter karta hai; content_total_cap badhao
  WAF block kar raha hai            -> --profile stealth (rate+jitter+UA rotation);
                                      phir bhi 403s aaye to modules unhe evidence
                                      me record karte hain, blind force mat karo
  nmap permission error             -> nmap XML nahi mila to socket scan fallback chalta hai
  httpx python vs ProjectDiscovery  -> export PATH="$HOME/go/bin:$PATH"
  Ctrl+C ke baad dobara chalana     -> wahi command; --fresh sirf jab zero se chahiye
  corrupt checkpoint                -> python3 wasp.py doctor --fix
  findings khaali                   -> modules poore hue? status dekho; threshold
                                      --min-sev info karke dekho
  report nahi bana                  -> pehle kam se kam ek module complete karo
  Sab kuch verify karna             -> python3 wasp.py selftest  (50 checks)
